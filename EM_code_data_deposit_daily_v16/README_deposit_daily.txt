DATA AND CODE DEPOSIT (DAILY-FREQUENCY VARIANT)
===============================================
Paper: "Associative Memory, Path-Dependent Beliefs, and Asset Pricing
Dynamics: A Deep Learning Approach" (Economic Modelling submission)

This is the daily-frequency companion to the code/data deposit of the
monthly (base) submission. The empirical strategy is identical to the
monthly pipeline; only the observational frequency changes. See results_daily/
FREQUENCY_COMPARISON.md for a side-by-side comparison of the two.

Contents
--------
04_solver.py                Path-dependent Deep BSDE solver (shared with base
                            deposit). ~15 s per configuration on Apple MPS.
05_model_analysis.py        Comparative statics, momentum/smirk analysis, and
                            model-implied predictability checks; writes figures.
09b_model_predictability.py In-model predictability regression (fut ~ MRI).
                            Writes results_daily/model_predictability.json.
run_all_daily.py            Orchestrator. Run: python run_all_daily.py
01b_build_data_daily.py     Derives the daily panels (daily future excess return,
                            annualised next-21-trading-day realised-vol target,
                            CAPE/DP forward-filled from the last monthly value)
                            from the frozen data_real/ snapshots. No network needed.
02b_analysis_daily.py       Baseline and control predictive regressions at daily
                            frequency (CSI 300, S&P 500); Newey-West lags = 21.
03b_robustness_daily.py     Daily robustness battery (crisis exclusion,
                            winsorization, halves, recursive estimation, blocking
                            rescale 1 month -> 21 trading days, circular block
                            bootstrap of MRI, 2000 reps).
06b_identification_daily.py Test A (flexible controls), Test B (random-anchor
                            placebo, 500 repl., seed 20260807), Test C
                            (orthogonalised MRI). Uses the true US daily panel for
                            the US residual test (this fixes a pre-existing
                            panel-mix bug in the monthly 06_identification.py).
07b_make_tables_daily.py    Regenerates LaTeX tables in tables_daily/ from
                            results_daily/ CSVs, incl. table_freq_compare.tex
                            (monthly vs daily). Requires the sibling monthly
                            results/ directory (the base deposit) for the monthly
                            benchmark cells.
08b_frequency_comparison.py Generates results_daily/FREQUENCY_COMPARISON.md.

data_real/          Daily panels actually used (pre-computed; includes the two
                    new files csi300_daily_panel.csv and sp500_daily_panel.csv).
results_daily/      All daily outputs committed so reviewers can compare.
results/            Solver results (solver_results.json, model_analysis.json,
                    simulated_paths.npz, solver.pth) — theory-side outputs
                    shared with the base deposit.
tables_daily/       LaTeX table bodies regenerated by 07b_make_tables_daily.py.
figures/            Figure_1.pdf (simulated paths), Figure_loss.pdf (training
                    convergence), Figure_3.pdf (empirical MRI times series).

Key numbers
-----------
Daily CSI 300 (2005--2025, N=5,101 obs): full-control MRI coefficient -0.21 pp,
t = -4.71, adj. R^2 = 3.52%. Dese monthly-equivalent agg. point estimate -4.65 pp,
t = -4.15 (annualising daily HAC-21 SE). S&P 500: MRI insignificant (t = -0.86).
Model level effect: log(P/D) vs MRI t = -18.52 (n=8,192 paths).
These and every other number are cross-verified by 07 scripts.

Reproducibility
---------------
1. `python run_all_daily.py` reproduces every results_daily/ file (about 50s).
2. Model-side: `python 04_solver.py --stage all` (optional if results/ committed),
   `python 05_model_analysis.py`, `python 09b_model_predictability.py`.
3. Daily identification test B uses rng seed 20260807; placebo distribution
   reproducible (mean -0.282, sd 0.501, |t| 99th pctile 1.55, p<1/500).
   All results committed and hash-verified.
4. The submission zips (EM_submission_daily_v3.zip and
   EM_code_data_deposit_daily_v3.zip) contain the same code and data.
